Segurança importante

Tokens secretos (Access Tokens, Bearer Tokens) nunca devem ser salvos no navegador — qualquer pessoa com acesso ao dispositivo pode visualizá-los. Guarde-os em variáveis de ambiente no servidor ou em um gerenciador de segredos (ex.: AWS Secrets Manager, Vault).

Aqui são salvos apenas os identificadores públicos (IDs e Public Keys), que são seguros para o lado do cliente.

Mercado Pago

Integração de pagamento via Checkout Pro. Obtenha as chaves em mercadopago.com.br → Sua conta → Credenciais.

⚠️ Cole aqui o seu Access Token de Produção (começa com APP_USR-). Ele é salvo de forma segura no banco de dados e nunca aparece no código do site.
Encontre em: mercadopago.com.br → Meu negócio → Configurações → Credenciais → Produção.

EmailJS — Recuperação de senha

Configure o serviço de envio de e-mail para a função "Esqueci minha senha" dos clientes. Crie sua conta gratuita em emailjs.com (200 e-mails/mês grátis), crie um serviço de e-mail e um template com as variáveis {{to_email}}, {{to_name}}, {{temp_password}} e (opcional) {{from_email}}/{{reply_to}}.

Cotação automática por CEP (Melhor Envio)

Quando ativa, o checkout calcula o frete real até o CEP do cliente (Correios PAC/SEDEX + outras transportadoras). Enquanto não estiver configurada, o site usa a tabela manual por peso abaixo como reserva.

Marque só para testar sem gerar etiquetas reais.

Token do Melhor Envio: por segurança, o token NÃO é salvo aqui. Ele é configurado no servidor quando o plano Blaze for ativado, com o comando firebase functions:secrets:set MELHOR_ENVIO_TOKEN. Crie sua conta em melhorenvio.com.br e gere o token de API.

Frete pelos Correios (PAC e SEDEX) — tabela manual (reserva)

Usada quando a cotação automática acima não está configurada. Configure os valores por faixa de peso para PAC e SEDEX — o sistema calcula com base no peso total dos itens no carrinho.
